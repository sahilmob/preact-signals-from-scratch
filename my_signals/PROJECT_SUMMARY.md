# Project summary

This is an AI-assisted learning implementation of reactive primitives. Source and tests explore signals, effects, computed values, linked-list dependencies, batching, and advanced APIs.

Earlier notes claimed production readiness, feature parity, and coverage percentages without sufficient verification. Those claims have been removed. A passing-test proportion is not code coverage.

See the [current README](../README.md) and [validation notes](../VALIDATION.md). The advanced multiple-subscriber case remains failing; this work is not a drop-in replacement for Preact Signals.
